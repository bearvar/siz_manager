# 2.1.0

## Изменения

- Обновлен визуальный стиль приложения по референсам из `tmp_design/`.
- Зеленый/teal акцент референса заменен на голубой для кнопок, активных состояний и focus-ring.
- Обновлены глобальные стили Bootstrap-компонентов: кнопки, карточки, таблицы, формы, badges, alerts, dropdown.
- Исправлена структура `includes/header.html`: partial больше не содержит полный HTML-документ.
- Обновлен shell приложения: голубой sticky header с логотипом Rosseti слева, нейтральный canvas, footer с hairline border.
- Добавлены регрессионные тесты для CSS-токенов и структуры shell-шаблонов.

## Проверки

- `poetry run python manager/manage.py test core`
- `poetry run python manager/manage.py check`
- Ручная визуальная проверка ключевых страниц в браузере.
