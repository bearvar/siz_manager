# 2.1.1

## Изменения

- Добавлен глобальный переключатель темы для светлого и темного режима.
- Переключатель темы оформлен как компактная интерактивная иконка без видимых текстовых подписей.
- Исправлено раскрывающееся меню профиля в шапке: фамилия и имя теперь являются кликабельной кнопкой меню.
- Темная тема реализована в выбранном графитовом варианте.
- Для авторизованных пользователей тема сохраняется в профиле пользователя.
- Для гостей тема сохраняется в cookie браузера.
- Добавлены регрессионные тесты для модели, endpoint, cookie, шаблонов и CSS темы.

## Миграции и эксплуатация

- Добавлена миграция `users.0005_customuser_theme`.
- Перед применением миграции в production нужно выполнить резервное копирование БД через существующий backup-процесс.

## Проверки

- `poetry run python manager/manage.py makemigrations --check --dry-run`
- `poetry run python manager/manage.py test`
- `poetry run python manager/manage.py check`
- Ручная визуальная проверка светлой и графитовой тем в браузере.
