# 2.1.1 Theme Switcher Implementation Plan

> **For agentic workers:** REQUIRED WORKFLOW: use the repo-task-proof-loop. Keep task artifacts in `.agent/tasks/2.1.1-theme-switcher/`. Implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a global light/dark theme switcher using the approved graphite dark theme, persisting the choice in `CustomUser` for authenticated users and in a cookie for anonymous users.

**Architecture:** Store the canonical preference in `users.CustomUser.theme` for authenticated users. Store the local browser preference in a signed-by-scope plain cookie named `siz_theme` for every user, so anonymous users keep their theme and authenticated users get immediate local consistency. Render the selected theme server-side through a context processor to avoid flash, then use a small `fetch()` script for instant switching from the header.

**Tech Stack:** Django 5, Django templates, Bootstrap 5 static assets, local CSS in `manager/static/css/custom.css`, vanilla JavaScript in `manager/static/js/theme-switcher.js`, Poetry, Django test runner.

## Acceptance Criteria

AC1. Global header contains a light/dark theme switcher available on every page rendered through `base.html`.

AC2. Selected theme is applied server-side on initial render using `data-theme="{{ ui_theme }}"` on the root HTML element or body. There is no intentional flash from light to dark after page load.

AC3. Authenticated users persist theme in `users.CustomUser.theme`; logout/login and another request keep the saved preference.

AC4. Anonymous users persist theme in cookie `siz_theme`; reload and later visits in the same browser keep the selected theme.

AC5. Invalid theme values are rejected by the POST endpoint with HTTP 400 and do not update the user or cookie.

AC6. Graphite dark theme is implemented through CSS variables and covers global shell, header, links, buttons, cards, tables, forms, alerts, dropdowns, badges, footer, and focus states.

AC7. Existing URLs and business workflows remain unchanged. The only new URL is the theme endpoint.

AC8. Security basics are preserved:
- theme save endpoint is POST-only;
- endpoint uses Django CSRF protection;
- cookie uses `SameSite=Lax`;
- cookie `secure` flag follows `settings.SESSION_COOKIE_SECURE`;
- no secrets or personal data are stored in the cookie.

```python
from django.conf import settings

THEME_LIGHT = "light"
THEME_DARK = "dark"
THEME_CHOICES = (
    (THEME_LIGHT, "Светлая"),
    (THEME_DARK, "Темная"),
)
THEME_COOKIE_NAME = "siz_theme"
THEME_COOKIE_MAX_AGE = 60 * 60 * 24 * 365
SUPPORTED_THEMES = {THEME_LIGHT, THEME_DARK}


def normalize_theme(value):
    if value in SUPPORTED_THEMES:
        return value
    return None


def get_request_theme(request):
    if request.user.is_authenticated:
        user_theme = normalize_theme(getattr(request.user, "theme", None))
        if user_theme:
            return user_theme

    cookie_theme = normalize_theme(request.COOKIES.get(THEME_COOKIE_NAME))
    if cookie_theme:
        return cookie_theme

    return THEME_LIGHT


def set_theme_cookie(response, theme):
    response.set_cookie(
        THEME_COOKIE_NAME,
        theme,
        max_age=THEME_COOKIE_MAX_AGE,
        secure=getattr(settings, "SESSION_COOKIE_SECURE", False),
        httponly=True,
        samesite="Lax",
    )
```

```python
def set_theme(request):
    theme = normalize_theme(request.POST.get("theme"))
    if theme is None:

    if request.user.is_authenticated:
```

```javascript
(function () {
  function getCookie(name) {
    const cookies = document.cookie ? document.cookie.split("; ") : [];
    for (const cookie of cookies) {
      const parts = cookie.split("=");
      const key = decodeURIComponent(parts.shift());
      if (key === name) {
        return decodeURIComponent(parts.join("="));
      }
    }
    return "";
  }

  function setActiveTheme(theme) {
    document.documentElement.dataset.theme = theme;
    document.querySelectorAll("[data-theme-option]").forEach(function (button) {
      const isActive = button.dataset.themeOption === theme;
      button.classList.toggle("active", isActive);
      button.setAttribute("aria-pressed", isActive ? "true" : "false");
    });
  }

  function saveTheme(theme) {
    const body = new URLSearchParams();
    body.set("theme", theme);

    return fetch(window.sizTheme.themeEndpoint, {
      method: "POST",
      headers: {
        "Content-Type": "application/x-www-form-urlencoded",
        "X-CSRFToken": getCookie("csrftoken"),
      },
      body: body.toString(),
      credentials: "same-origin",
    });
  }

  document.addEventListener("DOMContentLoaded", function () {
    if (!window.sizTheme || !window.sizTheme.themeEndpoint) {
      return;
    }

    document.querySelectorAll("[data-theme-option]").forEach(function (button) {
      button.addEventListener("click", function () {
        const theme = button.dataset.themeOption;
        const previousTheme = document.documentElement.dataset.theme || window.sizTheme.current || "light";

        setActiveTheme(theme);
        saveTheme(theme).then(function (response) {
          if (!response.ok) {
            setActiveTheme(previousTheme);
          }
        }).catch(function () {
          setActiveTheme(previousTheme);
        });
      });
    });
  });
})();
```
