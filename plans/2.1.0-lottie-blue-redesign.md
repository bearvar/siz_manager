# 2.1.0 Lottie Blue Redesign Implementation Plan

> **For agentic workers:** REQUIRED WORKFLOW: use the repo-task-proof-loop. Keep task artifacts in `.agent/tasks/2.1.0-lottie-blue-redesign/`. Implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refresh the Django app design to match the `tmp_design/` light LottieFiles-style reference, using blue instead of green/teal for UI chrome.

**Architecture:** Use a shared CSS design layer over existing Bootstrap markup, then clean up the base/header/footer shell. Avoid page-by-page rewrites; add small template hooks only where global component styling cannot safely apply.

**Tech Stack:** Django 5 templates, Bootstrap 5 static assets, local CSS in `manager/static/css/custom.css`, Poetry, Django test runner.

- [ ] Add tests below. If `manager/core/tests.py` already exists during implementation, append these classes without deleting existing tests.

```python
from pathlib import Path

from django.conf import settings
from django.test import SimpleTestCase


class DesignStaticTests(SimpleTestCase):
    def test_custom_css_uses_blue_design_tokens(self):
        css_path = Path(settings.BASE_DIR) / "static" / "css" / "custom.css"
        css = css_path.read_text(encoding="utf-8")

        self.assertIn("--siz-color-brand-blue: #0ea5e9", css)
        self.assertIn("--siz-color-canvas: #f4f4f5", css)
        self.assertIn("--siz-color-border: #e4e4e7", css)
        self.assertNotIn("#019d91", css)

    def test_custom_css_styles_core_bootstrap_components(self):
        css_path = Path(settings.BASE_DIR) / "static" / "css" / "custom.css"
        css = css_path.read_text(encoding="utf-8")

        required_selectors = [
            ".top-navbar-container",
            ".btn-primary",
            ".card",
            ".table",
            ".form-control",
            ".dropdown-menu",
            "footer",
        ]
        for selector in required_selectors:
            with self.subTest(selector=selector):
                self.assertIn(selector, css)


class DesignTemplateTests(SimpleTestCase):
    def test_header_include_is_not_a_full_html_document(self):
        header_path = Path(settings.BASE_DIR) / "templates" / "includes" / "header.html"
        header = header_path.read_text(encoding="utf-8").lower()

        forbidden = ["<!doctype", "<html", "<head", "<body", "</html", "</body"]
        for token in forbidden:
            with self.subTest(token=token):
                self.assertNotIn(token, header)

    def test_base_template_owns_global_assets(self):
        base_path = Path(settings.BASE_DIR) / "templates" / "base.html"
        base = base_path.read_text(encoding="utf-8")

        self.assertIn("{% static 'css/bootstrap.min.css' %}", base)
        self.assertIn("{% static 'css/custom.css' %}", base)
        self.assertIn('class="app-shell"', base)
```

Important path note:
- `settings.BASE_DIR` is `.../siz_manager/manager`, so `Path(settings.BASE_DIR) / "static" / "css" / "custom.css"` points to `manager/static/css/custom.css`.
